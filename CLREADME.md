# Chrome Scripts: Staff Notes

Cobblestone Learning · *Learning. Creativity. Trust.*

A small collection of browser tools that add extra features to a web page while you use it. They work as bookmarklets: a bookmarklet is a bookmark that runs a tool instead of opening a page. You click it in your bookmarks bar and the tool appears on the page you are looking at.

## What you can do with it
- **Hosting reports** (`better-sg-reports.js`): turn our hosting provider's statistics pages into a clearer dashboard of server and site performance (CPU, memory and requests), with charts, printable reports and CSV exports.
- **Image extractor** (`ie-extractor.js`): list every image on a page in a panel, search by file name, alt text or stock photo ID, and download the images you choose.

## How to use it
1. Open the README in this repo and find the tool you want.
2. Create a new bookmark and paste the tool's bookmarklet text (it starts with `javascript:`) as the bookmark's address.
3. Go to the page you want to use it on and click the bookmark.
4. For the hosting reports, log in to the hosting control panel and open the statistics pages first, so the tool has data to work with.

## Good to know
- The tools run only in your own browser, on the page you have open. They do not change the website for anyone else.
- This repo is public on purpose: the bookmarklets load the latest version of each tool from a public file service, which only works with public repos. Never put anything private here.
- The list of tools in the README is written automatically each time a new tool is added.
